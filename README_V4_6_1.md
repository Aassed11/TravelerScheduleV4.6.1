# TRAVELER Schedule V4.6.1 — 휴지통 / 복원

주요 변경
- 일정 삭제를 즉시 완전삭제에서 '휴지통 이동'으로 변경
- 삭제한 일정과 연결 체크리스트를 30일 보관
- 설정 > 데이터 관리 > 휴지통
- 일정 목록에서도 휴지통 바로가기
- 휴지통에서 일정 복원
- 개별 완전 삭제 (2차 확인)
- 휴지통 전체 비우기 (2차 확인)
- 삭제 후 30일이 지난 항목은 자동 완전 삭제
- 홈/캘린더/검색/업무대시보드/위젯에서는 휴지통 일정 자동 제외
- Firebase에 deletedAt을 동기화하여 다른 기기에서도 휴지통 상태 유지
- 복원 시 일정 + 기존 체크리스트 함께 복원
- Room DB version 5 → 6 migration
